# 数据接入层与数据触发口

> 托管和自动化的核心是**客户池**。本技能不自带任何客户数据库：安装时由你声明并导入自己的数据；
> 之后所有动作都由数据变化触发（池低、新文件、到期跟进、新回复、退信异常……），不靠人记。

---

## 一、安装时必须声明的数据接入项

| 档案字段 | 是否必填 | 取值 | 对应工具 |
|---|---|---|---|
| `data_sources.customer_db` | **必填**（门禁校验） | `imported` 已导入 / `crm_sync` 从 CRM 导出再导入 / `none` 暂无，从零开发 | `data_import.py` |
| `data_sources.mail_route` | 建议 | `smtp_env` 单邮箱密钥 / `mailboxes` 多邮箱托管 / `mcp` 连接器 / `not_yet` | `mail_setup.py`，见 `references/mail_setup.md` |
| `data_sources.mail_provider` | 建议 | `tencent_exmail` / `aliyun_qiye` / `netease_qiye` / `gmail` / `microsoft365` / `custom` | `mail_setup.py providers` |
| `data_sources.crm` / `crm_route` | 选填 | `hubspot` / `salesforce` / `okki` / `fumeng` / `other` / `none`；`csv` / `api` / `mcp` | `crm_sync.py` |
| `data_sources.saas_sources` | 选填 | 在用的外贸 SaaS / 海关平台名 | 见 `references/外贸SaaS对接指引.md` |

`python3 scripts/onboarding.py start` 会逐项显示状态和下一条命令；`ask` 会逐项问你。

## 二、客户库 `customer_db.csv`

```bash
python3 scripts/data_import.py fields                     # 标准字段 + 能自动识别的中英文列名
python3 scripts/data_import.py inspect 老客户.xlsx          # 只读预览映射
python3 scripts/data_import.py import 老客户.xlsx --relation existing_customer --source own:excel
python3 scripts/data_import.py import 线索.csv --relation prospect --source saas:平台名
python3 scripts/data_import.py stats
```

- 支持 `.csv`（UTF-8 / UTF-8-BOM / GB18030 自动识别）和 `.xlsx`；老 `.xls` 先另存为 `.xlsx`。
- 去重：先按邮箱，再按「域名 + 公司名」；已有记录只补空字段，不覆盖。
- 关系优先级：`do_not_contact` > `existing_customer` > `lost` / `competitor` > `prospect`。表里自带「客户类型」列时按行识别（老客户 / 潜在客户 / 流失 / 退订 / 投诉 / 同行等）。
- `do_not_contact` 的邮箱自动同步进 `blacklist.csv`，发信前检查会拦截。
- 老客户、禁联、同行不进冷开发可发池；老客户走复购与生命周期。
- 每次导入写 `import_log.csv`（时间、文件、来源、关系、行数、新增、补全）。

## 三、CRM 同步 `crm_sync.py`

| 路径 | 命令 | 说明 |
|---|---|---|
| CSV（任何 CRM） | `export --target hubspot\|salesforce\|okki\|fumeng\|generic` | 导出成对方导入向导好映射的列名；中文 CRM 用通用中文列名，导入时在向导里核对一次映射 |
| CSV 回拉 | `pull CRM导出.csv [--map 原列名=标准字段]` | 只更新本地已有邮箱的阶段 / 负责人 / 关系 / 最近联系，不新增陌生人 |
| HubSpot API | `push-hubspot` | 调 `POST /crm/v3/objects/contacts/batch/upsert`，以 email 为唯一键（[HubSpot 文档](https://developers.hubspot.com/docs/api-reference/legacy/crm/objects/contacts/guide)）；默认 DRY_RUN，`HUBSPOT_TOKEN` + `CRM_PUSH=1` 才真推；禁联和同行不推 |
| MCP | `mcp-payload` | 生成 `reports/crm_mcp_payload.json`，AI 通过 CRM 的官方 MCP（如 HubSpot 远程 MCP `https://mcp.hubspot.com`）只处理 `approved=true` 的条目 |

每次同步写 `crm_sync_log.csv`；触发口据此判断是否该同步了。

## 四、数据触发口 `triggers.py`

```bash
python3 scripts/triggers.py scan                # 生成 reports/trigger_queue.json 并打印
python3 scripts/triggers.py scan --apply-safe   # 允许保护性动作：退信异常时暂停托管邮箱
python3 scripts/triggers.py ack <key> ...       # 标记已处理
python3 scripts/triggers.py reviewed            # 记录本周已复盘
```

| 触发口 | 数据来源 | 触发条件 | 下一步 | 人工拍板 |
|---|---|---|---|---|
| `POOL_LOW` | customer_db + sent_history | 可发 < 红线，或只够 < 提前量天数；客户库为空 | `replenish` 四维补池 | 否（只出搜索词） |
| `NEW_IMPORT_FILE` | `data/inbox/` + import_log | 出现未导入的 CSV/XLSX | `data_import inspect` → `import` | 是（确认关系与来源） |
| `COOLDOWN_DUE` | sent_history | 已过冷却期（第1/2封后 3 天，第3封后 10 天；与 `csv_ops.py` 一致），非老客户/禁联 | 写跟进 → DRY_RUN | 是 |
| `REPLY_RECEIVED` | sent_history（imap_scanner 回写） | 状态为 replied | 人工回复 → 第六/七步 | 是 |
| `BOUNCE_SPIKE` | sent_history | 近 7 天发送 ≥ 20 且退信率 > 阈值（默认 5%，可调默认值） | 暂停托管邮箱、清洗名单 | 否（保护性，可自动） |
| `WA_SIGNAL` | wa_contacts | 有 new / pending 线索 | 第七步 WhatsApp | 是 |
| `WARMUP_STEP` | mailboxes.json | 某邮箱今天进入新预热档位 | 仅提示 | 否 |
| `MAILBOX_PAUSED` | mailboxes.json | 有邮箱暂停中 | 排查后 `resume` | 是 |
| `CRM_SYNC_DUE` | customer_db + crm_sync_log | 从未同步，或客户库有更新且距上次 ≥ N 天 | `crm_sync export / pull` | 是 |
| `WEEKLY_REVIEW` | trigger_state | 距上次周复盘 ≥ 7 天 | 第零步复盘 + 七件套写回 | 是 |

**铁律**：触发口只读扫描、写队列；任何「发出去」的动作（邮件、WhatsApp、推 CRM）都标 `needs_human=true`。唯一允许自动执行的是保护性的暂停。

## 五、每日自动化（挂一次就行）

```bash
# cron 示例：每天 08:30 扫触发口，09:00 补池出词
30 8 * * * cd /你的技能目录 && B2B_DATA_DIR=data python3 scripts/triggers.py scan --apply-safe >> reports/cron.log 2>&1
0 9 * * *  cd /你的技能目录 && B2B_DATA_DIR=data python3 scripts/search_customers.py replenish --emit queries_today.txt >> reports/cron.log 2>&1
```
平台定时任务、Windows 任务计划的挂法见 `references/automation_setup.md`。

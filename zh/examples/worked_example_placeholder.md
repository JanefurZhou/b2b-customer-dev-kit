# 案例（Worked Example）— 首次建档后替换

本技能是全行业通用的脱敏模板，**不内置任何真实公司案例**。完成首次建档
（`scripts/onboarding.py` 输出 `READY`）后，建议在这里补一个你自己行业的
脱敏样例，固化打法。可按下面骨架填写，尖括号内容全部替换为你的真实情况。

## 样例骨架（占位，非真实）

- **公司/品牌**：<your-brand>
- **行业 / 交付形态**：<business.industry> / <business.offer_type>
- **核心产品/服务**：<your-core-offer，来自 product.one_liner_en>
- **起步方式**：<offer.entry_offer>
- **目标客户**：<buyer role> @ <channel / company type>，地区 <region>
- **搜索词组合**：
  - 产品词：<primary_keyword> + 角色词：<buyer_title> + 渠道词：<channel>
  - 排除：<exclude_keyword>
- **背调结论**：该客户销售 <相关品类>、有 <采购信号>、决策人是 <name/role>。
- **切入钩子**：基于 <differentiator> 的一句话价值主张。
- **邮件结果**：<sent / reply / bounce>，下一步 <action>。

> 在你填入真实案例前，本节视为「案例 N/A」——方法论见
> `references/industry_playbooks.md` 与 `references/search_guide.md`，
> 所有业务字段以 `config/company_profile.json` 为准。

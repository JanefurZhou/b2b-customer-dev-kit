# 行业适配指南（任何行业 10 分钟接入）

> 本 Skill 的流程（搜索 → 背调 → 定标签 → 写邮件 → 发送 → 跟进 → WhatsApp → 复盘）对所有 B2B 业务都一样。
> 不同行业只有三样东西不同：**找谁**、**在哪找**、**怎么让对方低风险地开始**。
> 这三样分别落在 profile 的 `targeting`、`search`、`offer` 三段里，其余脚本和规则一律不用改。

---

## 一、三步接入

```
1. 选行业包（方法层建议，可跳过）
   python3 scripts/onboarding.py packs                # 看 13 个内置包
   python3 scripts/onboarding.py pack saas_software   # 看某个包的全部建议
   python3 scripts/onboarding.py init                 # 生成空白档案
   python3 scripts/onboarding.py apply-pack saas_software
      → 只往【仍为空】的方法层字段写建议：客户分层、决策角色、渠道词、意图词、推荐渠道、排除词
      → 公司事实（品牌、联系人、产品词、卖点、offer.*）一律不写
      → user_confirmed 自动重置为 false

2. 填公司事实（ask 交互式，或 AI 按 onboarding_questions.md 逐项问）
   business.industry / business.offer_type / company.* / product.* / offer.* / contact.*

3. 回读 → 用户逐项改成自己的说法 → 明确确认 → attest 激活
```

行业包写进去的只是"起点草稿"。比如 `industrial_b2b` 写入的 `L1_oem` 分层，你要改成自己真实的客户类型（"注塑机厂""泵阀整机厂"），这样搜索式才会准。

## 四、两个标签：行业无关的背调结论

| 标签 | 回答的问题 | 取值 | 谁来定义 |
|---|---|---|---|
| `need_tag` | 客户要你**哪条**产品/服务线？ | 你自定义：`positioning.need_tags`（如 `line_a`/`line_b`）+ 保留值 `multi`/`unknown`/`review` | 你 |
| `solution_tag` | 客户做决定**最在意什么**？ | 11 个通用决策驱动：`compliance` `sustainability` `quality_upgrade` `cost` `speed` `low_commitment` `innovation` `exclusive_custom` `one_stop` `dedicated_service` `strategic_scale`（+ `open`/`unknown`） | 固定，全行业通用 |

- 邮件钩子按 `solution_tag` 选（`industry_playbooks.md` §七）；脚本缺省会回落读取 `hook_type` / `need_tag`。
- 需要"某线与某类客户不能并存"这类行业规则时，在 `positioning.tag_rules` 里写，`conflict-check` 会自动执行：

```json
"positioning": {
  "need_tags": ["line_a", "line_b"],
  "conflict_groups": {"need_tag": [["line_a"], ["line_b"]]},
  "tag_rules": [
    {"if_field": "variant_tag", "equals": "on_premise", "forbid_field": "solution_tag",
     "values": ["low_commitment"], "reason": "私有化部署没有低门槛试用"}
  ],
  "hooks": {"cost": "Teams switching to us usually cut {lead}. {second}."}
}
```

## 六、接入后自检

```bash
python3 scripts/onboarding.py start                 # 装好后马上要补的信息（三关状态一览）
python3 scripts/onboarding.py kit-check             # 灵魂七件套内容体检，须 7/7
python3 scripts/onboarding.py check                 # 必填项（含 business.industry / offer_type）+ 确认状态
python3 scripts/search_customers.py social --regions <一个目标国> | head -30   # 社媒公开搜索式是否贴合你的客户
python3 scripts/search_customers.py channels        # ▶ 标记的就是默认渠道，确认符合你行业
python3 scripts/search_customers.py queries --regions <一个目标国> | head -20   # 看搜索式是否像"你的客户"会出现的页面
DRY_RUN=1 python3 scripts/decision_maker_sender.py preview.json reports   # 看开场句与收尾问句是否通顺
```

搜索式里出现你行业不会用的词（如软件公司看到 "wholesale"）→ 回 `targeting.channel_keywords` / `search.intent_terms` 改；
邮件收尾问句不对味 → 改 `offer.cta_question`。
改完技能包本身（脚本或文档）后，跑 `python3 scripts/consistency_audit.py`，须 FAIL 0。
